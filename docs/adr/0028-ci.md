# Continuous integration on GitHub Actions, Windows only

**Status:** accepted (2026-11-01)

`.github/workflows/ci.yml` runs one job on `windows-latest`. The game and the app target Windows only ([ADR-0003](0003-windows-only.md)), and the user does not support Linux builds, so CI does not run on Linux.

Steps: `npm ci` → format check → lint → type check → unit and integration tests with coverage → end-to-end tests (Playwright, real window) → `npm run dist:win` → `npm audit --audit-level=high` (report only).

- **Triggers:** push to `master`, pull requests, manual run. A newer push on the same branch cancels the older run (`concurrency`). The repository is private, so minutes count, and Windows minutes count twice.
- **Artifacts:** the Windows build (about 310 MB unpacked) only for pushes and manual runs, kept 7 days; the Playwright report and traces only when a step fails, kept 7 days. Artifact storage counts against the private repository quota.
- **Line ends:** `.gitattributes` forces LF on every checkout (`* text=auto eol=lf`). Git for Windows would check files out with CRLF, and `oxfmt --check` expects LF. The user's `README.md` first kept its original CRLF (`-text`) and oxfmt ignored it; since ADR-0030 it is an English project README with LF, formatted like the other files.
- **Native packages:** oxlint, oxfmt, rolldown and the TypeScript 7 compiler are native. The lock file (made on Linux) contains their `win32-x64` packages; if `npm ci` on Windows ever misses one, regenerate the lock file with all platforms rather than adding the package by hand.
- **Action versions:** `actions/checkout@v6`, `actions/setup-node@v6`, `actions/upload-artifact@v6` (Node 24 runtime; GitHub removes Node 20 for actions in 2026).
- **Audit:** `npm audit` is a report only: the known moderate `minimatch` finding is in the build tools (electron-builder), and its automatic fix would downgrade electron-builder.

## Consequences

CI runs only after a push to GitHub. The pre-commit hook ([ADR-0026](0026-oxlint-and-oxfmt.md)) keeps commits formatted, lint-clean and typed before they reach CI.
